### 🧪 How to Evaluate the Laravel Samples

These examples are extracted from real business logic developed for the Laravel version of Mi Negocio.

They are provided as focused code samples rather than as a standalone Laravel application.

Each example demonstrates a specific aspect of business application development:

## 🧩 Laravel Code Samples — Real-world Business Logic

[— Dynamic database queries and pagination](examples/dynamic-patient-search-pagination.php)

A Laravel Query Builder example implementing multi-field patient search, soft-delete filtering and paginated results for a responsive business application.

[— Compact representation and processing of clinical data](examples/clinical-data-vaccination-bitmask.php)

A compact representation of multiple boolean clinical fields using a binary string, reducing the number of individual database fields required for vaccination status.

[— Laravel Blade interfaces and business logic](examples/paciente-list.blade.php)

A Laravel Blade view demonstrating layouts, reusable components, dynamic data rendering, conditional business logic, route generation, CSRF protection, pagination and CSP-aware JavaScript integration.

The complete Mi Negocio application is currently under development.

### 🧪 Cómo evaluar los ejemplos de Laravel

Estos ejemplos están extraídos de lógica de negocio real desarrollada para la versión Laravel de Mi Negocio.

Se presentan como ejemplos de código enfocados, en lugar de una aplicación Laravel independiente y completa.

Cada ejemplo demuestra un aspecto específico del desarrollo de aplicaciones empresariales:

## 🧩 Ejemplos de Código Laravel — Lógica de Negocio Real

[— Consultas dinámicas a la base de datos y paginación](php-laravel/examples/dynamic-patient-search-pagination.php)

Un ejemplo de Laravel Query Builder que implementa búsqueda de pacientes por múltiples campos, filtrado de registros eliminados lógicamente y resultados paginados para una aplicación empresarial adaptable a dispositivos móviles.

[— Representación compacta y procesamiento de datos clínicos](php-laravel/examples/clinical-data-vaccination-bitmask.php)

Una representación compacta de múltiples campos clínicos booleanos mediante una cadena binaria, reduciendo la cantidad de campos individuales necesarios para almacenar el estado de vacunación.

[— Interfaces Laravel Blade y lógica de negocio](php-laravel/examples/paciente-list.blade.php)

Una vista Laravel Blade que demuestra el uso de layouts, componentes reutilizables, renderizado dinámico de datos, lógica de negocio condicional, generación de rutas, protección CSRF, paginación e integración de JavaScript compatible con CSP.

La aplicación completa de Mi Negocio se encuentra actualmente en desarrollo.
